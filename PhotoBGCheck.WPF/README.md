# 证件照背景检测工具 (PhotoBGCheck.WPF)

## 项目简介

这是一个专业的证件照背景检测 WPF 应用程序，用于批量检测学生证件照的背景是否符合白底要求。

**✨ 支持双模式检测：快速模式 + AI智能模式**

## 检测模式

### 🚀 快速模式（默认）
- **速度**：毫秒级处理（每张<50ms）
- **准确率**：85-90%
- **原理**：检测照片上方角落区域，结合肤色/深色过滤
- **优点**：速度快，无需额外模型文件
- **适用场景**：快速批量检测，立即可用

### 🤖 AI智能模式
- **速度**：每张约0.5秒
- **准确率**：92-95%
- **原理**：MODNet人像分割 + 全背景白色检测
- **优点**：准确率更高，能精确区分人像和背景区域
- **要求**：需要下载MODNet模型文件（~25MB）
- **适用场景**：高精度要求的检测

## 主要功能

### 核心功能
- ✅ **双模式切换**：快速模式/AI智能模式自由切换
- ✅ **文件夹选择**：选择包含证件照的文件夹
- ✅ **批量检测**：自动检测所有 JPG/PNG 格式的证件照
- ✅ **智能算法**：快速模式使用角落检测，AI模式使用人像分割
- ✅ **实时进度**：显示检测进度条
- ✅ **详细统计**：显示总数、合格数、不合格数和合格率
- ✅ **可视化展示**：以缩略图形式展示不合格照片
- ✅ **导出功能**：导出不合格照片列表（TXT/CSV格式）
- ✅ **一键打开**：快速在资源管理器中打开照片文件夹

### 检测参数（可调节）
- **检测模式**：快速模式/AI智能模式（默认：快速模式）
- **白色阈值**：RGB值大于此值才被视为白色（默认：210）
- **白色占比**：背景中白色像素占比大于此值才算合格（默认：75%）

### 配置持久化
- 自动保存上次选择的文件夹
- 自动保存检测参数设置
- 自动保存检测模式选择
- 自动保存窗口大小

## 检测算法说明

### 快速模式算法
1. **上方双角采样法**：只检测图片左上角和右上角区域（各20% x 20%），避开下方的肩膀、西装等
2. **智能过滤**：自动排除检测区域内的肤色和深色像素（头发边缘），只统计纯背景像素
3. **白色判定**：
   - RGB 三个通道的值都要大于白色阈值
   - RGB 三个通道的值要相近（色差小于15），避免偏色
4. **合格标准**：
   - 白色像素占背景比例 ≥ 设定值（默认75%）
   - 背景平均亮度 ≥ 白色阈值（默认210）

### AI智能模式算法
1. **人像分割**：使用MODNet深度学习模型精确分割人像区域
2. **背景提取**：剔除人像后，检测全部背景区域（不仅仅是角落）
3. **白色判定**：同快速模式，检测背景像素是否为白色
4. **合格标准**：同快速模式，但检测范围覆盖全部背景

### 参数调整建议
- **严格检测**：白色阈值 = 230，白色占比 = 90%
- **标准检测**：白色阈值 = 210，白色占比 = 75%（默认）
- **宽松检测**：白色阈值 = 200，白色占比 = 70%

## 使用说明

### 基本操作流程
1. **选择文件夹**：点击"选择文件夹"按钮，选择包含证件照的文件夹
2. **调整参数**（可选）：根据需要调整白色阈值和白色占比
3. **开始检测**：点击"开始检测"按钮
4. **查看结果**：
   - 检测完成后会显示统计信息
   - 不合格的照片会以缩略图形式展示
   - 可以看到每张照片的白色占比和背景亮度
5. **导出列表**（可选）：点击"导出列表"保存不合格照片的详细信息

### 快捷操作
- **在文件夹中打开**：快速打开照片所在文件夹
- **导出格式选择**：支持 TXT（便于阅读）和 CSV（便于导入 Excel）

## 注意事项

1. **支持的图片格式**：JPG、JPEG、PNG
2. **检测速度**：取决于图片数量和分辨率，通常每秒可处理10-20张
3. **内存占用**：采用流式处理，内存占用较小
4. **配置保存**：所有设置会自动保存，下次启动时恢复

## 常见问题

### Q: 为什么有些明显是白底的照片被判定为不合格？
A: 可能是因为：
- 照片的白色不够"纯"（偏黄或偏蓝）
- 背景有阴影或杂质
- 可以适当降低白色阈值或白色占比来放宽标准

### Q: 如何提高检测的准确性？
A: 
- 先用默认参数检测一批照片
- 查看不合格照片，评估是否符合实际需求
- 根据实际情况微调参数

### Q: 导出的列表文件在哪里？
A: 导出时会弹出保存对话框，您可以选择保存位置
