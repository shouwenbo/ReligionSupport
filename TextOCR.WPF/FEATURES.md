# TextOCR.WPF 功能说明

## 核心功能

### 1. PaddleOCR 3.3.1 集成
- ✅ 使用官方推荐参数初始化
- ✅ UTF-8 编码支持，完美处理中文
- ✅ 自动过滤无关警告信息
- ✅ 启动时自动测试 PaddleOCR 是否正常工作

### 2. 智能字幕提取
- ✅ **实时进度显示**：显示总帧数和当前进度
  - 格式：`处理帧: 10/100 (10.0%) - 已识别字幕: 5 条`
- ✅ **智能去重**：与原始 TextOCR.py 相同的逻辑
  - 提取中文字符进行比较
  - 连续帧相同文字自动忽略
  - 只保存文字发生变化的帧
- ✅ **内存处理**：不保存临时图片到磁盘
  - OpenCV 直接在内存中处理视频帧
  - 减少磁盘 I/O，提高处理速度

### 3. 临时文件管理
- ✅ **启动时清理**：自动清理旧的临时文件
  - 清理 `ocr_temp_*.png` 
  - 清理 `debug_subtitle_*.png`
- ✅ **提取后清理**：完成字幕提取后自动清理
- ✅ **智能过滤**：只删除程序生成的临时文件

### 4. 输出格式
- ✅ **TXT 格式输出**：纯文本格式
- ✅ **智能标点**：自动添加逗号分隔
  - 没有标点符号的句子自动加逗号
  - 保留原有标点符号
- ✅ **完成后提示**：询问是否立即打开结果文件

### 5. 用户体验优化
- ✅ **简洁界面**：只显示 PaddleOCR 结果
- ✅ **实时日志**：所有操作都有日志记录
- ✅ **进度条**：实时显示提取进度百分比
- ✅ **设置保存**：所有参数自动保存
- ✅ **视频信息**：自动显示分辨率、帧率、时长

## 技术细节

### OCR 识别流程
1. **初始化**：PaddleOCR 使用 3.3.1 官方参数
2. **帧提取**：根据帧间隔提取视频帧
3. **区域裁剪**：提取字幕区域（顶部/底部）
4. **OCR 识别**：使用 `ocr.predict()` 方法
5. **结果解析**：提取 `rec_texts` 属性
6. **智能去重**：比较中文字符，过滤重复
7. **保存结果**：输出到 TXT 文件

### 进度计算
- 计算需要处理的帧数：`总帧数 / 帧间隔`
- 实时更新进度：`已处理帧数 / 总帧数 * 100%`
- 显示识别字幕条数：实时统计去重后的字幕数量

### 去重算法（与原始 TextOCR.py 一致）
```python
# 提取汉字部分
current_text_chinese = extract_chinese_characters(current_text)
last_text_chinese = extract_chinese_characters(last_text)

# 只保存不同的文本
if current_text_chinese and current_text_chinese != last_text_chinese:
    output_text.append(current_text)
    last_text = current_text
```

## 使用建议

1. **帧间隔设置**
   - 字幕变化快：0.3-0.5 秒
   - 字幕变化慢：0.5-1 秒
   - 节省时间：1-2 秒（可能遗漏部分字幕）

2. **字幕高度**
   - 通过预览功能调整
   - 确保完整包含字幕区域
   - 不要包含过多背景内容

3. **性能优化**
   - PaddleOCR 初始化较慢（首次约 10 秒）
   - 后续识别速度较快
   - 长视频建议使用时间范围分段处理

## 已知限制

- 仅支持中文字幕识别
- 需要 Python 3.10+ 和 PaddleOCR 3.3.1
- Windows 10/11 系统
- 首次启动需要下载模型文件（自动）
